# 管理画面設計書

## 1. 概要

非エンジニアでも簡単にホームページのコンテンツを更新できる管理画面を構築します。

## 2. 機能要件

### 2.1 認証機能

- Supabase Auth を使用したログイン/ログアウト
- 管理者のみがアクセス可能
- セッション管理

### 2.2 ニュース管理

- ニュース記事の一覧表示
- 新規作成・編集・削除
- 画像アップロード（サムネイル）
- プレビュー機能
- バリデーション（必須項目チェック）

### 2.3 募集情報管理

- 募集情報の一覧表示
- 新規作成・編集・削除
- 職種、部署、勤務形態の選択
- 責任・要件のリスト管理
- バリデーション

### 2.4 チームメンバー管理

- チームメンバーの一覧表示
- 新規作成・編集・削除
- プロフィール画像のアップロード
- グリッド位置の設定（row, column, offsetY）
- バリデーション

### 2.5 投資家グループ管理

- 投資家グループの一覧表示
- 新規作成・編集・削除
- サポーターリストの管理
- バリデーション

## 3. UI/UX 要件

### 3.1 デザイン原則

- **シンプルで直感的**: 非エンジニアでも迷わず操作できる
- **一貫性**: Atlas ブランドのデザインシステムに準拠
- **レスポンシブ**: モバイル・タブレット・デスクトップ対応
- **アクセシビリティ**: キーボード操作、スクリーンリーダー対応

### 3.2 レイアウト

```
┌─────────────────────────────────────┐
│  Header (ロゴ + ログアウト)          │
├──────────┬──────────────────────────┤
│          │                          │
│  Sidebar │  メインコンテンツエリア   │
│  - ニュース                          │
│  - 募集情報                          │
│  - チームメンバー                    │
│  - 投資家グループ                    │
│          │                          │
└──────────┴──────────────────────────┘
```

### 3.3 コンポーネント設計

- **リストビュー**: テーブル形式で一覧表示、検索・フィルタ機能
- **フォーム**: 各項目の入力フォーム、リアルタイムバリデーション
- **モーダル**: 確認ダイアログ、プレビュー表示
- **画像アップロード**: ドラッグ&ドロップ対応、プレビュー表示

## 4. 技術実装

### 4.1 認証

- Supabase Auth（Email/Password）
- RLS ポリシーで管理者のみアクセス可能に設定

### 4.2 データ操作

- Supabase Client を使用した CRUD 操作
- リアルタイム更新（オプション）

### 4.3 画像管理

- Supabase Storage に画像をアップロード
- 公開 URL を取得してデータベースに保存

### 4.4 バリデーション

- クライアント側: React Hook Form + Zod
- サーバー側: Supabase の制約と RLS ポリシー

## 5. セキュリティ

- 認証必須: 未認証ユーザーはアクセス不可
- RLS ポリシー: 管理者のみ書き込み可能
- CSRF 対策: Supabase のセキュリティ機能を活用
- XSS 対策: React の自動エスケープ

## 6. 実装フェーズ

### Phase 1: 認証機能とニュース管理（最優先）

1. 認証機能の実装
2. ニュース管理画面の実装
3. 画像アップロード機能

### Phase 2: 募集情報管理

1. 募集情報管理画面の実装
2. リスト項目の動的管理

### Phase 3: チームメンバー管理

1. チームメンバー管理画面の実装
2. グリッド位置設定 UI

### Phase 4: 投資家グループ管理

1. 投資家グループ管理画面の実装
