# Atlas ホームページ - プロダクト要件定義書（PRD）

## 1. プロダクト概要

### 1.1 プロジェクト名

Atlas コーポレートホームページ

### 1.2 プロジェクトの目的

Atlas 社の公式ホームページを開発し、ブランドアイデンティティを反映したクリーンでモダンな Web サイトを構築する。

### 1.3 プロジェクトの背景

- ブランドのオンラインプレゼンスを確立する
- 会社情報、製品・サービス、採用情報などを提供する
- レスポンシブデザインにより、あらゆるデバイスで最適な体験を提供する

---

## 2. デザイン要件

### 2.1 デザインコンセプト

- **ミニマリストでクリーンなデザイン**
- **余白を活かした広々としたレイアウト**
- **白と黒を基調としたモノクロデザイン**

### 2.2 カラーパレット

- **主要色**
  - 白（`#FFFFFF`）：メインコンテンツの背景
  - 黒（`#000000`）：テキスト、ロゴ、ナビゲーション、バナーの背景

### 2.3 タイポグラフィ

- セリフ体をメインコンテンツに使用（参考画像のスローガン部分）
- サンセリフ体をナビゲーションやその他の UI 要素に使用
- フォントサイズはレスポンシブに対応

### 2.4 レイアウト要件

- **広々とした余白設計**
- **中央揃えのコンテンツ配置**

---

## 3. 機能要件

### 3.1 ヘッダー/ナビゲーション

- **ナビゲーションメニュー**
  - デスクトップ：横並び表示
  - モバイル：ハンバーガーメニューに変更
  - リンク項目（要検討）：
    - Home
    - Products / Services
    - About
    - Careers
    - Contact
- **ロゴ表示**
  - ナビゲーションの下、中央に配置
  - Atlas ブランドロゴ（またはブランドシンボル）
- **タイムスタンプ表示**（オプション）
  - 右上に現在の日時を表示
  - リアルタイム更新

### 3.2 メインコンテンツエリア

- **ヒーローセクション**
  - 中央に大きく表示されるスローガン/メッセージ
  - タイピングエフェクトやアニメーションの検討
  - 例：「We believe that your next favorite human... isn't.」（参考）
- **セクション構成**（要検討）
  - About Atlas
  - Products / Services
  - Features / Benefits
  - News / Updates
  - Contact / CTA

### 3.3 通知バナー/ニュースセクション

- **位置**: メインコンテンツエリアの下部
- **機能**:
  - 最新ニュースやお知らせを表示
  - 画像サムネイル + テキストの形式
  - クリックで詳細ページまたは外部リンクに遷移
  - 展開アイコンで視覚的に示す

### 3.4 フッター

- コピーライト情報
- ソーシャルメディアリンク（オプション）
- 追加のナビゲーションリンク

---

## 4. レスポンシブデザイン要件

### 4.1 ブレークポイント

- **モバイル**: < 768px
- **タブレット**: 768px - 1024px
- **デスクトップ**: > 1024px

### 4.2 レスポンシブ対応項目

- **ナビゲーション**
  - モバイル：ハンバーガーメニューに変換
  - タブレット/デスクトップ：横並び表示
- **タイポグラフィ**
  - 画面サイズに応じてフォントサイズを調整
  - メインスローガンはモバイルで適切なサイズに縮小
- **レイアウト**
  - コンテンツエリアの幅を画面サイズに応じて調整
  - 余白とパディングをレスポンシブに設定
- **画像・メディア**
  - レスポンシブ画像の使用
  - 画像のアスペクト比を維持
- **通知バナー**
  - モバイルでは縦積みレイアウトに変更
  - 画像とテキストの配置を最適化

---

## 5. 技術要件

### 5.1 技術スタック

- **フレームワーク**: Next.js 16
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS 4
- **コード品質**: Biome

### 5.2 パフォーマンス要件

- ページ読み込み速度の最適化
- 画像の最適化（Next.js Image コンポーネントの使用）
- コード分割とレイジーローディング

### 5.3 アクセシビリティ要件

- WCAG 2.1 AA 準拠を目指す
- キーボードナビゲーション対応
- スクリーンリーダー対応
- 適切なコントラスト比の確保

### 5.4 SEO 要件

- メタタグの適切な設定
- セマンティック HTML の使用
- 構造化データの実装（必要に応じて）

---

## 6. コンテンツ要件

### 6.1 必須コンテンツ

- 会社概要（About）
- 製品・サービス情報
- 採用情報（Careers）
- お問い合わせ情報

### 6.2 コンテンツ管理

- 将来的に CMS 連携を検討（現在はハードコーディング）
- ニュース・お知らせの更新方法を検討

## 7. 優先順位

### 7.1 Phase 1（MVP - 最小限の機能）

1. ヘッダー/ナビゲーション
2. ヒーローセクション（メインスローガン）
3. 基本的なセクション（About, Products, Careers）
4. フッター
5. レスポンシブデザイン対応

### 7.2 Phase 2（拡張機能）

1. 通知バナー/ニュースセクション
2. アニメーション・インタラクティブ要素
3. 詳細ページ（各セクションの詳細ページ）
4. お問い合わせフォーム

### 7.3 Phase 3（将来的な拡張）

1. CMS 連携
2. ブログ機能
3. 多言語対応
4. 高度なアニメーション

## 8. 成功指標

### 8.1 パフォーマンス指標

- Lighthouse スコア 90 以上
- ページ読み込み時間 3 秒以内
- モバイルでのページ読み込み速度の最適化

### 8.2 UX 指標

- レスポンシブデザインが全デバイスで適切に動作
- アクセシビリティ基準の達成
- ブランドアイデンティティの反映

### 9.1 技術的制約

- ミニマリストデザインの維持
- 参考画像のデザインをベースに拡張
